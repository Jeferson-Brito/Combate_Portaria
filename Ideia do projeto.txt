# PROJETO — SISTEMA DE CONTROLE DE ACESSO E VISITANTES

Quero desenvolver um sistema profissional de **Controle de Acesso e Gestão de Visitantes**, inicialmente como aplicativo mobile em **React Native**, com backend próprio e integração com WhatsApp utilizando a biblioteca **Baileys**.

O sistema deverá ser desenvolvido pensando em produção, segurança, escalabilidade e possibilidade de comercialização futura como um produto SaaS.

O aplicativo deverá funcionar em:

- Android
- iOS

Também quero que o projeto seja preparado para distribuição:

- Google Play Store
- Apple App Store
- Distribuição direta fora das lojas quando tecnicamente permitida pela plataforma

IMPORTANTE:

O aplicativo mobile NÃO deve se comunicar diretamente com o Baileys.

A arquitetura deverá ser:

**React Native App → API/Backend → Banco de Dados**

e

**Backend → Serviço WhatsApp/Baileys → WhatsApp**

O Baileys deverá funcionar exclusivamente no backend/servidor.

---

# 1. OBJETIVO DO SISTEMA

O sistema tem como objetivo substituir processos manuais de controle de acesso realizados atualmente através de grupos de WhatsApp, ligações ou mensagens individuais.

Exemplo:

Um residencial possui vários apartamentos.

Um visitante chega à portaria e informa:

> "Vim visitar o apartamento 8."

Atualmente o porteiro pode enviar uma mensagem em um grupo do WhatsApp:

> "Visitante João da Silva aguardando na portaria para o apartamento 8."

O morador responde:

> "Pode liberar."

O porteiro então permite a entrada.

O novo sistema deverá automatizar e organizar todo esse processo.

O porteiro deverá cadastrar a visita no aplicativo.

O sistema enviará automaticamente uma mensagem pelo WhatsApp para o cliente/morador responsável pelo destino.

O cliente poderá:

- Autorizar
- Recusar

O resultado deverá retornar automaticamente para o sistema e aparecer para o porteiro.

# 70. IMPORTANTE SOBRE O WHATSAPP

O sistema deverá tratar a integração com WhatsApp como uma dependência externa sujeita às regras e mudanças do WhatsApp.

O Baileys é uma biblioteca que interage com o WhatsApp Web e não deve ser tratado como uma API oficial do WhatsApp.

Implementar a integração de forma desacoplada para que futuramente seja possível substituir Baileys por outra solução, inclusive uma API oficial, sem precisar reescrever todo o sistema.

Criar uma interface como:

WhatsAppProvider

com métodos semelhantes a:

connect()

disconnect()

sendMessage()

sendApprovalRequest()

sendReminder()

handleIncomingMessage()

getConnectionStatus()

Dessa maneira, futuramente poderá existir:

BaileysProvider

OfficialWhatsAppProvider

etc.
